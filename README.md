# KYR Taller para Windows

Taller de dibujo técnico **CAD 2D y 3D** en español, de **KYR Soluciones Educativas**.
Funciona sin internet y guarda tus dibujos en DXF para abrirlos en AutoCAD.

## ⬇ [Descargar KYR Taller (.exe)](https://github.com/jamesasd8-del/kyr-taller-descargas/releases/latest/download/KYR-Taller-Setup.exe)

Windows 10 y 11 · 64 bits · gratis

### Cómo instalarlo
1. Descarga `KYR-Taller-Setup.exe` y ábrelo desde tu carpeta Descargas.
2. Si Windows muestra **«Windows protegió su PC»**, haz clic en **Más información → Ejecutar de todas formas**
   (aparece porque el programa aún no tiene firma digital).
3. Sigue el asistente: **Siguiente → Instalar → Terminar**. No pide permisos de administrador.
4. Abre **KYR Taller** desde el ícono del escritorio o el menú Inicio.

¿No puedes instalar programas? Úsalo en el navegador: **https://www.kyrsoluciones.cl/taller/**
